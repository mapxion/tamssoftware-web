Protección de datos

Política de privacidad

Esta página explica el tratamiento básico de la información que el usuario envía voluntariamente para solicitar información, una demostración o soporte.

Responsable

Intelsi Telecomunicaciones, S.L.. Contacto: soporte@tamssoftware.es.

Datos tratados

Podrán tratarse los datos incluidos en el correo enviado por el usuario, como nombre, empresa, dirección electrónica, teléfono y contenido de la consulta.

Finalidad y base jurídica

Los datos se utilizan para responder consultas, preparar demostraciones o presupuestos y prestar soporte. La base es la solicitud del interesado y, cuando corresponda, la ejecución de medidas precontractuales o contractuales.

Conservación y destinatarios

Los datos se conservarán durante el tiempo necesario para gestionar la consulta y cumplir obligaciones legales. No se prevé su venta a terceros.

Derechos

Puede solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad escribiendo a soporte@tamssoftware.es.

Vídeos externos

Los reproductores de YouTube se cargan únicamente cuando el usuario pulsa sobre la miniatura. A partir de ese momento, YouTube puede aplicar sus propias tecnologías y políticas.
